# MCP

На старте проекта MCP намеренно не используется.

Причина:
- проект локальный;
- все исходники находятся в репозитории;
- тесты и build запускаются локально;
- внешние данные для расчётов V0-MVP не нужны.

Добавлять MCP только когда появляется конкретная потребность во внешнем инструменте/источнике.

Если MCP будет добавлен:
- project config хранить в `.cursor/mcp.json`;
- секреты передавать только через environment variables;
- не коммитить API keys/tokens;
- каждое подключение документировать здесь: зачем оно нужно, какие tools предоставляет и какие права имеет.
